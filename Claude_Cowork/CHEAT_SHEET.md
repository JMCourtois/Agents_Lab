# Claude Cowork Cheat Sheet

## Best Fit

Use Cowork for:

- research packs
- synthesis memos
- knowledge organization
- desktop and connector-backed work
- turning messy inputs into clean outputs

## Fast Start

1. Gather the files.
2. Define the output.
3. Ask for extraction.
4. Ask for synthesis.
5. Ask for validation.

## Prompt Shapes That Work Well

### Extract

```text
Read these files and extract the key facts, unresolved questions, and contradictions. Keep the output structured.
```

### Synthesize

```text
Using the extracted notes, write a one-page memo for a beginner reader. Keep it practical and honest.
```

### Validate

```text
Review the memo for unsupported claims, missing evidence, and places where the confidence is too high.
```

## Pattern Fit

- Single-agent workflow: excellent
- Review loop: strong
- Routing as staged task design: strong
- Repo-local subagent architecture: not the main lesson here

## Common Mistakes

- dumping too many files into one vague task
- skipping output format
- confusing synthesis with proof
- forcing Cowork into a code-first workflow
