# Claude Cowork Track

## When To Use This Tool

Use Claude Cowork when the main job is desktop knowledge work rather than repository-centered coding.

This track is the best fit if your work looks like:

- gathering files
- synthesizing research
- producing decision memos
- organizing information
- moving from messy inputs to clear outputs

## What You Will Learn Here

- how to structure Cowork tasks around files and deliverables
- how to separate extraction, synthesis, and validation
- how to use repeatable task templates even without repo-local subagent files
- how to compare Cowork honestly against coding-first tools

## Honest Positioning

This repo does not treat Cowork as "Claude Code with a different name."

It treats Cowork as:

- a desktop-oriented agent experience
- a strong fit for knowledge work and synthesis
- a good place to learn artifact-driven workflows outside a codebase
