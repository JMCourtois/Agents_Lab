# Claude Cowork Best Practices

## 1. Start with an input pack

Before asking Cowork to do anything meaningful, gather:

- the main brief
- the supporting files
- the output format

## 2. Separate extraction from synthesis

Do not always ask for everything at once.

A better sequence is:

1. identify the key facts
2. identify tensions or open questions
3. synthesize the final memo

## 3. Use explicit output formats

Good output requests:

- decision memo
- comparison table
- one-page brief
- structured checklist

## 4. Keep the audience visible

The same research pack should produce different outputs for:

- a beginner
- a manager
- a technical peer

Name the audience every time.

## 5. Validate before you trust

Ask Cowork to check:

- unsupported claims
- missing evidence
- contradictions between sources
- parts that sound too certain

## 6. Use connectors with intent

Connectors are useful when they reduce manual gathering, not when they flood the task with noise.

## 7. Save reusable task shapes

The repeatable unit in Cowork is often:

- a brief template
- a synthesis template
- a validation checklist

not a repo-local agent file.
