# Claude Cowork Setup

## What You Need

- Access to Claude Cowork or the Anthropic desktop environment that exposes the workflow you want to practice.
- A local file set or connected sources to work from.

## Important Note

Public Anthropic materials were more explicit about Cowork's positioning than about every low-level product primitive.

Because of that, this track teaches Cowork through:

- file packs
- structured requests
- synthesis workflows
- validation passes

instead of through repo-local subagent files.

## Practical Setup Advice

1. Make a folder with the documents you want Cowork to use.
2. Name the files clearly.
3. Decide the output before you start.
4. If connectors are available in your environment, use them only when they improve the task.

## Good Starter Workflow

Use this sequence:

1. collect inputs
2. extract key facts
3. synthesize
4. validate against the brief

## If Cowork Access Is Limited

You can still use this track as a thinking framework inside Claude Desktop with local files and connector-backed research.

The key lesson is not the exact UI. The key lesson is how to structure knowledge-work tasks so the agent has:

- a clear input pack
- a clear output format
- a clear validation step
