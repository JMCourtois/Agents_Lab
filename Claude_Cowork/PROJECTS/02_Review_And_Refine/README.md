# Project 02: Review And Refine

## Goal

Use Cowork as a reviewer and reviser for a weak internal draft.

## Suggested Workflow

1. Read [starter_assets/draft.md](Agents_Lab/Claude_Cowork/PROJECTS/02_Review_And_Refine/starter_assets/draft.md).
2. Ask for weaknesses and missing cautions.
3. Ask for a cleaner revised version.
4. Ask for a final validation pass.

## Suggested Prompt

```text
Review this draft for vague advice, missing cautions, unsupported confidence, and weak structure. Then rewrite it into a stronger version and finally validate the revised memo.
```
