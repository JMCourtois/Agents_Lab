# Project 02: Review And Refine

## Goal

Use Codex in a maker-checker pattern.

Start from a weak draft, critique it, and improve it.

## Suggested Workflow

1. Read [starter_assets/draft.md](/Users/jean/Documents/Halfway/Coding/Github Projects/Agents_Lab/Codex/PROJECTS/02_Review_And_Refine/starter_assets/draft.md).
2. Ask Codex for a bug-first or weakness-first review.
3. Ask for a revised version using the review findings.
4. Ask for remaining risks.

## Suggested Prompt

```text
Review this draft as if it were about to be shared with a team. Focus on weak structure, vague claims, missing cautions, and places where the advice is too generic. Then rewrite it into a stronger final version.
```
