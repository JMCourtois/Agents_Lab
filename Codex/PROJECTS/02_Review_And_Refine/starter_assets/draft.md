# Agent Task Intake Guide

When using AI, write a prompt and be specific. It is important to be clear and ask for the result you want. AI is very powerful and can do many things, so if you provide enough detail it should work well.

You should also ask it to be careful. If you want a better answer, maybe ask it to think harder or do more research. Sometimes multiple agents are useful because different agents can do different jobs.

You should also probably save important things somewhere because chats can get long. It is useful to review outputs, especially if the task is important.

Overall the main thing is to write a good prompt and then let the AI help.
