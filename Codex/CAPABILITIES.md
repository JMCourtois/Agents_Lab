# Codex Capabilities

This page focuses on capabilities that OpenAI publicly describes clearly as of March 27, 2026.

## What It Is Good At

### Repository work

Codex can:

- read code
- modify files
- run commands
- answer questions about a codebase
- help draft and review implementation work

### Parallel coding workflows

OpenAI positions the Codex app as a command center for multiple agents, with:

- multiple threads
- built-in worktrees
- parallel tasks across projects
- long-running task supervision

### Cloud delegation

Codex cloud runs tasks in isolated cloud containers, which is useful for:

- background coding work
- reviewable outputs
- sandboxed experiments
- repo-connected tasks that continue outside your active session

### Skills and automations

OpenAI's Codex materials describe:

- Skills for reusable team-aligned workflows
- Automations for scheduled or recurring coding work

### Coding-specific model support

OpenAI publishes Codex models optimized for coding and agentic software tasks, and also documents Codex across CLI, IDE, app, and cloud surfaces.

## Smallest Useful Example

Give Codex:

- one clear objective
- one repo
- one success definition
- one validation step

Example:

```text
Find the failing checkout logic, fix it with the smallest safe change, run the relevant tests, and summarize any remaining risk.
```

## Why This Matters

Codex becomes much more useful when you stop treating it like a chat tab and start treating it like:

- an execution environment
- a review partner
- a parallel coding workspace
