# Codex Track

## When To Use This Tool

Use Codex when the main artifact is code and you want an agent that can read repositories, modify files, run commands, review diffs, and work in parallel across tasks.

Codex is the best starting point in this repo if you think in terms of:

- issues
- pull requests
- tests
- refactors
- code review
- long-running coding tasks

## What You Will Learn Here

- how to prompt Codex for focused coding work
- how to keep specs and outputs reviewable
- how to use review loops instead of one-shot coding prompts
- how to think about parallel agents, worktrees, and cloud tasks without losing control

## Honest Positioning

Codex is not presented here as a full replacement for a desktop knowledge-work agent.

This track treats Codex as:

- a coding agent
- a repo-native worker
- a parallel task environment
- a strong fit for code review, debugging, testing, and implementation work
