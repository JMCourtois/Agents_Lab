# Learning Path

This repo is designed so you can use it in two ways:

- As a guided path when you are learning from zero.
- As a quick reference when you already know the basics and just need a reminder.

## Recommended First Pass

### Stage 1: Build the mental model

- Read [GLOSSARY.md](/Users/jean/Documents/Halfway/Coding/Github Projects/Agents_Lab/GLOSSARY.md).
- Read the first half of [AGENT_ARCHITECTURES.md](/Users/jean/Documents/Halfway/Coding/Github Projects/Agents_Lab/AGENT_ARCHITECTURES.md), especially the foundations and core patterns.
- Read [DECISION_MATRIX.md](/Users/jean/Documents/Halfway/Coding/Github Projects/Agents_Lab/DECISION_MATRIX.md).

Expected time: 45 to 60 minutes.

### Stage 2: Pick one tool

If you mostly want code-first workflows, start with [Codex](/Users/jean/Documents/Halfway/Coding/Github Projects/Agents_Lab/Codex).

If you mostly want project-local agent roles and repo-native orchestration, start with [Claude_Code](/Users/jean/Documents/Halfway/Coding/Github Projects/Agents_Lab/Claude_Code).

If you mostly want desktop execution, research, synthesis, and file-heavy knowledge work, start with [Claude_Cowork](/Users/jean/Documents/Halfway/Coding/Github Projects/Agents_Lab/Claude_Cowork).

### Stage 3: Do the three shared projects

Each tool track starts with the same three project shapes:

1. `01_Single_Agent_Workflow`
2. `02_Review_And_Refine`
3. `03_Agent_Routing`

This is the easiest way to compare the tools without getting distracted by vendor-specific extras.

### Stage 4: Do the tool-specific project

After the shared projects, do the extra project that shows the tool's natural strengths:

- Codex: `04_Codebase_Task`
- Claude Code: `04_Project_Subagents`
- Claude Cowork: `04_Desktop_Research_Workflow`

### Stage 5: Compare across tools

Once you finish one full track, open the same project number in another tool folder and compare:

- What was easier?
- What needed more structure?
- What depended on features the other tool does not expose as clearly?

## How To Revisit Later

When you come back after a few weeks, use this order:

1. [CHEAT_SHEET.md] inside the tool you plan to use.
2. [DECISION_MATRIX.md] if you are unsure about the workflow.
3. The specific project folder if you want a practice run.
4. [AGENT_ARCHITECTURES.md] only when you need a deeper pattern comparison.

## What To Learn First

Do not start with swarm, autonomous teams, or long-running orchestration.

Start with:

- clear task briefs
- structured outputs
- review loops
- routing decisions
- explicit success criteria

That foundation transfers cleanly across every tool in this repo.
