# Project 01: Single Agent Workflow

## Goal

Use Claude Code as one focused worker inside a project.

Do not create subagents yet.

## Suggested Workflow

1. Read [brief.md](Agents_Lab/Claude_Code/PROJECTS/01_Single_Agent_Workflow/brief.md).
2. Open [starter_assets/raw_brief.md](Agents_Lab/Claude_Code/PROJECTS/01_Single_Agent_Workflow/starter_assets/raw_brief.md).
3. Ask Claude Code to turn it into a concise internal note.
4. Ask for one self-critique pass before finalizing.

## Suggested Prompt

```text
Turn this rough brief into a concise onboarding note for a new teammate. Keep it practical, structured, and short enough to revisit later. After drafting it, critique weak points and then provide a revised final version.
```
