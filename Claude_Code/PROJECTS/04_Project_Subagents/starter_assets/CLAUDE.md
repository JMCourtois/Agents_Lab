# Project Purpose

This tiny project exists to teach a beginner how project memory and subagents can work together.

## Current Goal

Turn the rough notes in `drafts/feature_notes.md` into a clear contributor playbook for new teammates.

## Working Rules

- Prefer short reusable documents.
- Keep suggestions practical.
- Do not invent advanced process unless it clearly helps.
- Review meaningful output before calling it done.
