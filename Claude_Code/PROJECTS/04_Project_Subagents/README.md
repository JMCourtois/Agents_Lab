# Project 04: Project Subagents

## Goal

Use a real starter pack with `CLAUDE.md` and project subagents.

This is the track's signature project.

## What You Will Practice

- reading project memory
- inspecting `.claude/agents/`
- routing work across stable roles
- keeping state in files instead of in one huge conversation

## Suggested Workflow

1. Open the `starter_assets/` folder as its own tiny project.
2. Read `CLAUDE.md`.
3. Inspect `.claude/agents/`.
4. Read `notes/project_state.md` and `drafts/feature_notes.md`.
5. Ask Claude Code to use the existing roles to create a better contributor playbook.
6. Finish with a review pass.

## Suggested Prompt

```text
Read the project memory and subagent definitions, then produce a contributor playbook from the existing notes. Use the planner to structure the work, the researcher to identify gaps, and the reviewer to critique the result before finalizing it.
```
