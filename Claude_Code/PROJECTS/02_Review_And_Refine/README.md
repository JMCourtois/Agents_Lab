# Project 02: Review And Refine

## Goal

Practice the reviewer loop before you design more elaborate routing.

## Suggested Workflow

1. Read [starter_assets/draft.md](Agents_Lab/Claude_Code/PROJECTS/02_Review_And_Refine/starter_assets/draft.md).
2. Ask Claude Code to review it with a skeptical mindset.
3. Ask for a revised version.
4. Ask for remaining weaknesses.

## Suggested Prompt

```text
Review this draft for weak structure, vague advice, missing cautions, and places where it sounds more confident than it should. Then rewrite it into a stronger final version.
```
