# Agent Task Intake Guide

When using AI, it helps to write a good prompt and include the result you want. AI can do many things, so a clear prompt is often enough. If you want more quality, maybe ask it to think more deeply or to be careful.

Sometimes it is useful to use multiple agents, because different agents can do different parts of the work. It is also good to save information somewhere and review important outputs if the task matters.

In general, if you explain the task, AI will usually help a lot.
