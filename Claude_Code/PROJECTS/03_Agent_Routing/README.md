# Project 03: Agent Routing

## Goal

Design a small role system for Claude Code.

This project introduces the idea of routing without making you build a large subagent system yet.

## Suggested Workflow

1. Read [starter_assets/task_inbox.md](Agents_Lab/Claude_Code/PROJECTS/03_Agent_Routing/starter_assets/task_inbox.md).
2. Ask Claude Code to propose 3 or 4 stable project roles.
3. Turn the result into a short routing policy.

## Suggested Prompt

```text
Read the task inbox and design a small Claude Code routing policy. Propose 3 or 4 project roles, describe what each role owns, and say which tasks should go straight to a single agent versus a review loop.
```
