# Claude Code Track

## When To Use This Tool

Use Claude Code when you want agent workflows that live with the project itself.

This is the best starting point in the repo if you care about:

- `CLAUDE.md`
- project-local instructions
- subagents in `.claude/agents/`
- MCP-connected workflows
- terminal-native coding with reusable specialist roles

## What You Will Learn Here

- how to keep project memory in `CLAUDE.md`
- how to design simple project subagents
- how to route tasks cleanly instead of using one giant prompt
- how to build lightweight multi-agent workflows without pretending every task needs a swarm

Claude Code is not just "a model in a terminal."

- a good environment for lightweight orchestration inside a repo
